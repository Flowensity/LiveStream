# 手机横屏播放菜单（信号源/画面比例/节目单）体验优化设计规范

## 1. 背景与意图 (Intent & Why)

在手机横屏播放流媒体时，用户点击呼出「播放菜单」（`EpgScheduleDialog`）后，目前界面为固定宽度 264dp 的单一竖向抽屉。
在此抽屉中，信号源切换卡片、画面比例选择卡片和今日节目单呈纵向垂直堆叠。由于手机横屏状态下屏幕物理高度受限（通常仅 360dp ~ 410dp 左右），固定高度的顶部卡片消耗了超过 60% 的纵向空间，导致底部的「今日节目单」有效显示区域不足 100dp，最多只能露出一到两个节目，严重影响了查看节目排期的体验。

本次优化意在解决横屏下垂直空间受挤压的问题，充分发挥手机横屏水平宽幅的优势，提供舒展、高效、且不打扰左侧视频画面的交互体验。

---

## 2. 目标与非目标 (Goals & Non-Goals)

### 目标 (Goals)
1. **大幅提升横屏节目单可视区域**：在横屏模式下，今日节目单列表可独占纵向全高，可视节目条目从 1~2 项提升至 5~6 项，滚动体验流畅。
2. **保持控制触达效率**：信号源切换与画面比例选择依然即时可见、一键直达，无需二级页面或 Tab 切换跳转。
3. **触控人体工学优化**：画面比例 4 档胶囊在左栏采用 2×2 双排网格排布，增大手指点按命中面积，杜绝文字缩写或截断。
4. **设备兼容性与平滑降级**：
   - 手机竖屏（Portrait）以及电视 TV 模式保持原有单列交互逻辑不变，不产生破坏性回归；
   - 抽屉宽度在极窄横屏屏幕上自适应约束（最大不超过屏幕宽度的 58%）。

### 非目标 (Non-Goals)
- 不改动电视端（TV Leanback）的 D-pad 焦点导航上下流转逻辑。
- 不修改底层信号源探测、切换机制及 EPG 解析加载逻辑。

### 反目标 (Anti-Goals)
- 避免全屏遮罩把视频彻底挡住（必须保留至少 40%~50% 的左侧动态视频视野）。
- 避免增加深层级折叠菜单或弹窗嵌套。

## 4. 方案评估与决策 (Approaches)

在前期调研中对比了三种构想：
- **方案一（双栏分列布局，已选定）**：抽屉在横屏下宽度自适应扩展至约 440dp，内部采用左右分栏：左栏控制（信号源+画面比例），右栏展示节目单。
- **方案二（顶部分段 Tab 切换）**：保持 264dp 抽屉，通过 Tab 在「节目单」和「设置」间切换。缺点是调整信号源需多一次点击。
- **方案三（单列紧凑压制）**：将卡片高度硬性压窄，缺点是在 264dp 宽度内密集堆砌按钮会导致误触和视觉拥挤。

**选定理由**：用户选定方案一。方案一最能发挥宽屏空间优势，同时兼顾「全功能直达」与「大视野节目单」。

## 5. 详细界面与交互实现 (Detailed Implementation)

### 5.1 设备与横屏状态识别
在 `EpgScheduleDialog.kt` 中：
```kotlin
val configuration = LocalConfiguration.current
val deviceType = rememberDeviceType()
val isTv = deviceType == DeviceType.TV
val isPhoneLandscape = !isTv && (
    deviceType == DeviceType.PHONE_LANDSCAPE || 
    configuration.orientation == Configuration.ORIENTATION_LANDSCAPE
)
```

### 5.2 抽屉尺寸与外框适配
- **竖屏 / TV**：抽屉宽度维持 `OneUiDimensions.panelPlaylistWidth` (264.dp)。
- **手机横屏 (`isPhoneLandscape`)**：
  - 宽度设定：`val drawerWidth = min(440.dp, (configuration.screenWidthDp * 0.58f).dp)`；
  - 外边距设定：`padding(start = 8.dp, top = 12.dp, bottom = 12.dp, end = 12.dp)`；
  - 圆角与底色延续 OneUI 风格。

### 5.3 内部布局架构
```
+---------------------------------------------------------------+
|  播放菜单 · 频道名称                                     [关闭]  |
+-------------------------------+-------------------------------+
| [左栏 - 线路与画面控制] (约190dp) | [右栏 - 今日节目单] (自适应剩余宽度)|
|                               |                               |
| +---------------------------+ | 今日节目单 (05-18) · 共 18 档  |
| | 信号源切换 (1/3)           | | +---------------------------+ |
| | 默认主线路 · 延迟 85ms     | | | 14:00 - 15:30             | |
| | [切换下一线路]             | | | [正在播出] 经典剧场       | |
| +---------------------------+ | +---------------------------+ |
|                               | | 15:30 - 16:45             | |
| +---------------------------+ | | 新闻直播间                | |
| | 画面比例 (当前: 16:9)     | | +---------------------------+ |
| | [原始比例]   [16:9 标准]   | | | 16:45 - 18:00             | |
| | [4:3 经典]   [裁剪全屏]   | | | 晚间剧场预告              | |
| +---------------------------+ | +---------------------------+ |
|                               | | ... (纵向充足展示 5~6 项)   | |
+-------------------------------+-------------------------------+
```

1. **顶部公共标题栏**：
   - 保持简明，左侧频道名称与副标题，右侧「关闭」胶囊按钮。
2. **左栏（控制区）**：
   - 宽度固定约为 `185.dp` ~ `195.dp`；
   - 包含信号源卡片与画面比例卡片；
   - 画面比例 4 档按钮改为 2 行 × 2 列的对称胶囊网格，按钮文字完整展示（“原始比例”、“16:9 标准”、“4:3 经典”、“裁剪全屏”），不再被截断。
3. **右栏（节目单区）**：
   - 占用剩余宽度（`weight(1f)`）；
   - 包含今日日期、节目总数，以及直达底部的 `LazyColumn` 列表；
   - 保持自动滚动到「正在播出」节目项的逻辑。
